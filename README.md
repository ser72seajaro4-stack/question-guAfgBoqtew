# フロント業務アンケート

GitHub Pages で公開し、回答を FormSubmit 経由でメールに自動送信するアンケートページ。
ページはパスワードで暗号化してあり、パスワードを知っている人だけが開ける。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 暗号化したアンケート（パスワード入力画面つき） |
| `tools/encrypt.mjs` | HTMLをパスワードで暗号化するツール |
| `tools/salt.txt` | 暗号化に使う塩（消さないこと） |

暗号化前のアンケート（平文の HTML・CSS・JavaScript）は、このリポジトリには置かない。
リポジトリは公開されているため、平文を置くと中身やメールアドレスが誰でも読めてしまう。

## しくみ

- パスワードから PBKDF2（SHA-256、60万回）で鍵を作り、AES-GCM（256bit）で暗号化している。
- ページを開くとパスワード入力画面だけが表示され、正しいパスワードを入れたときだけ
  ブラウザの中で復号してアンケートを表示する。
- パスワードはどこにも保存していない。ソースを見てもパスワードや中身は分からない。
- 同じタブで一度パスワードを入れれば、タブを閉じるまでは入力を省略できる。
- パスワードを5回続けて間違えると、1時間入力できなくなる。正しく入力すると回数は0に戻る。
  （記録はそのブラウザに残すため、同じ端末・同じブラウザの中だけで有効）
- 検索エンジンに載らないよう `noindex, nofollow` を指定している。

## アンケートを更新するとき

1. 手元にある暗号化前のファイル（index.html・style.css・script.js）を直す。
2. 3ファイルを1つの HTML にまとめる（CSS と JavaScript をページの中に入れる）。
3. Node.js 18 以上で暗号化して、`index.html` を上書きする。

   ```sh
   PAGE_PASSWORD='パスワード' node tools/encrypt.mjs まとめた.html index.html
   ```

4. `index.html` だけをコミットする。

## 公開の設定

- Settings → Pages → Branch を `main` / `(root)` にして Save。
- 回答の送信先は FormSubmit で有効化済み。送信先を変えるときは、平文の `script.js` の
  先頭にある設定を書き換えてから暗号化し直す。

## 回答の届き方

- 1件の回答につき1通のメールが届く。
- 件名：`フロント業務アンケート回答（名前）`（名前が空なら名前なし）
- 本文：質問と回答が表形式で並ぶ。未回答の項目は「（未回答）」。

## 注意

- パスワードを知っている人は、ページを開いて中身（送信先を含む）を見ることができる。
- この変更より前のコミット履歴には、暗号化前のファイルが残っている。
- FormSubmit は無料の外部サービス。回答はこのサービスを経由してメールに届く。

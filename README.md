# フロント業務アンケート

GitHub Pages で公開し、回答を FormSubmit 経由でメールに自動送信するアンケートページ。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | ページの骨組み |
| `style.css` | 見た目 |
| `script.js` | 質問の中身・送信処理（送信先の設定は先頭） |

## 公開までの手順

1. **リポジトリに上げる**
   GitHub で新しいリポジトリを作り、3つのファイルをアップロードする。

2. **GitHub Pages を有効にする**
   リポジトリの Settings → Pages → Branch を `main` / `(root)` にして Save。
   数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける。

3. **FormSubmit を有効化する（最初の1回だけ）**
   - 公開したページで、テストとして一度回答を送信する。
   - `ser72seajaro4@gmail.com` に FormSubmit から確認メールが届くので、
     中の「Activate Form」ボタンを押す。
     （迷惑メールフォルダに入ることがある）
   - 有効化前の最初の送信は、ページ上で「送信できませんでした」と出ることがある。
     有効化後にもう一度送ればメールが届く。

4. **（おすすめ）メールアドレスを隠す**
   有効化後に届くメールに、ランダムな文字列のフォームアドレスが書かれている。
   `script.js` の先頭を次のように書き換えると、ページのソースにアドレスが載らなくなる。

   ```js
   const FORM_TO = "ここにランダムな文字列";
   ```

   `MAIL_TO`（送信に失敗したときに画面に出す手動送信用のアドレス）は
   そのままでも、消したい場合は別のアドレスに変えてもよい。

5. **スタッフにURLを配る**

## 回答の届き方

- 1件の回答につき1通のメールが届く。
- 件名：`フロント業務アンケート回答（名前）`（名前が空なら名前なし）
- 本文：質問と回答が表形式で並ぶ。未回答の項目は「（未回答）」。

## その他の仕様

- 必須項目は「0-1 主に入る店舗」のみ。
- 入力途中の内容は、その端末のブラウザに自動保存される（送信成功で消える）。
- 送信に失敗したときは、回答テキストのコピーと手動送信の案内が表示される。
- 質問を変えるときは `script.js` の `SECTIONS` を編集する。

## 注意

- FormSubmit は無料の外部サービス。回答はこのサービスを経由してメールに届く。
- 無料版には送信数などの制限がある。人数の多い職場で使う場合は、
  FormSubmit の公式サイトで最新の条件を確認しておくこと。
